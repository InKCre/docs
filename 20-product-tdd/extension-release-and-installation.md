# Extension Release 与安装契约

本契约定义 Extension 发布者、Registry、开发工具和宿主共同消费的交付完整性及安装语义。原生包的构建、上传验证与宿主 SDK 兼容判断分别由对应 Unit 拥有，不在这里增加通用目标匹配器或跨格式可执行包。

## 发布身份与交付承诺

Extension Name 与精确 SemVer 标识一个 Release。Python 和 Module Federation 是该 Release 的独立原生分发，原生项目版本必须与 Release 版本一致；两侧不能用不同版本拼成一次交付。各分发的来源、宿主 SDK 范围、关联元数据与产物保持各自的权威。

发布者决定本版本要交付的最小原生格式集合。新 Release 准备请求必须显式声明非空、无重复的 `required_native_formats`，其成员限定为 `python` 和 `module_federation`。承诺按精确 Release 固定，后续 producer 准备同一 Release 时必须一致；Registry 不从历史版本、当前上传顺序或某个宿主的可用性猜测这项意图。

交付计划拥有精确版本及必需格式，原生 producer 与开发工具消费同一计划并在写入前核对版本与声明。原生项目可以只有一种格式；同时承诺两种格式的项目必须协调两侧版本及产物。第一方发布流程也遵守此规则，不能将各仓库的一次成功构建当作完整 Release 的交付证明。

承诺用于发布准备和发布者管理接口；公开 Release 描述继续表达实际可读的原生关联，不因完整性校验要求旧宿主读取新的发布元数据。承诺不进入 handler 参数、部署安装记录或 wheel 的执行描述。

## 发布完整性与历史边界

只有承诺的每种关联和产物均齐备，并且所有已关联分发都通过其原生对象校验，Release 才能进入 `published`。例如，承诺 Python 与 MF 而只上传 wheel 的 Release 必须保持不可安装的准备状态。Registry 拥有这一完整性判断；宿主仍拥有本地 SDK 兼容性、可执行能力和启用资格。

必需格式是最小交付集合，不禁止以后首次追加另一种原生关联。已有关联的元数据、文件名及内容身份不可覆盖；相同提交可幂等重试，冲突需要新 Release。下一版本可以明确承诺更小的格式集合，不能通过改写旧 Release 的承诺来移除已经发布的支持。

历史已发布 Release 没有这项承诺时，不推断或回填其过去意图，继续按实际关联提供读取，并允许合法首次补充缺失分发。历史准备状态必须先由发布者明确声明，再发布。新创建 Release 不接受未声明承诺的旧发布工具；工具升级与声明采用是发布者的明确迁移边界，不能保留一个可无限绕过校验的默认值。

## 部署安装与宿主启用

`installed` 是部署选定的精确 Release 及持久配置；`enabled` 是各 Peer 的运行意图；`running` 是该运行实例已完成启动。这些状态不能合并。安装本身不启用任何 Peer，也不证明某个宿主已下载或能运行所有分发。

Web 管理界面可以安装纯 Python Release 供 Core 使用，不能因浏览器宿主需要 MF 而禁止这种安装。启用时由目标宿主检查对应原生分发、SDK 范围与生命周期；没有 MF 的 Release 不能在 Web Peer 本地运行。

部署只有一个所选版本，版本变更影响所有 Peer。版本变更和卸载仍须遵守现有全部 Peer 停用及本地运行清理约束，不因本地宿主只支持某个版本而隐式降级、替换或重新派发管理写入。

版本变更默认保留已有原生分发支持。目标版本减少支持时，调用者必须明确确认具体支持变化；确认绑定原安装版本，不能套用到并发改动后的记录。合法的格式移除因此仍可完成，而不是被永久禁止。

旧 Release 因明确的不存在或封禁而无法读取时，调用者可以在明确确认支持信息不可核对后变更版本。临时网络或服务故障不能冒充格式移除或成为跳过检查的许可。用户界面展示变化并收集确认，SDK 拥有判断与写入边界，不在各界面复制一套安装规则。

## 交付与验证

契约由 Hub 先发布，各 Unit 分别交付 Registry、开发工具、原生 producer 和宿主消费者。发布工具必须采用新声明后，Registry 的新建拒绝边界才能投入使用；公开描述不变不代表旧发布工具仍能创建新 Release。

验收覆盖双格式缺一种时拒绝发布、单格式正常发布、声明冲突与版本错位、原生对象缺失、历史读取和首次补关联，以及下一版本合法移除格式。安装验收还需证明纯 Python 可从 Web 安装、减少支持需要明确确认、旧确认不能覆盖并发版本变更，以及旧 Release 封禁和暂时网络故障的不同结果。已经下载或正在运行的内容不因服务端状态改变而自动撤回。
